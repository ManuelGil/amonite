All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

Release family: **Nautilus** (Amonite 1.x).

Nautilus names the complete 1.x generation. Maturity labels describe the current state of a release; they are not a required sequence. See [branding.md](branding.md).

## [v1.0.0-alpha.2] - 2026-07-28

### Added

- Completed the intended Standard desktop integration for this Alpha 2 release.

### Changed

- Refined the Amonite Standard desktop experience while preserving the lightweight composition.
- Improved default desktop appearance consistency through selected runtime components and declarative configuration, without adding unnecessary background services or custom startup logic.

### Release

- Edition: Standard (Alpha 2)
- Release family: Nautilus
- Version maturity: alpha
- Architecture: `amd64`
- Image: `amonite-1.0.0-alpha.2-amd64.iso`
- Intended for evaluation and testing; not production-ready

## [lite/v1.0.0-alpha] - 2026-07-28

### Added

- Introduced the first public Amonite Lite Alpha release.
- Provided a lightweight desktop edition within the Nautilus release family.

### Release

- Edition: Lite (published Alpha)
- Release family: Nautilus
- Version maturity: alpha
- Architecture: `amd64`
- Image: `amonite-lite-1.0.0-alpha-amd64.iso`
- Intended for evaluation and testing; not production-ready

## [v1.0.0-alpha] - 2026-07-22

### Added

- Published the first public Amonite Standard release.
- Provided a curated Debian-based GNU/Linux desktop experience with Welcome handbook, modern terminal, curated command-line environment, local AI inference, and graphical installer.

### Release

- Edition: Standard (Alpha)
- Release family: Nautilus
- Version maturity: alpha
- Architecture: `amd64`
- Image: `amonite-1.0.0-alpha-amd64.iso`
- Intended for evaluation and testing; not production-ready
