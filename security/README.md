# Security

This directory contains the official public signing key used to verify Amonite
releases.

## Contents

| File                      | Description                          |
| ------------------------- | ------------------------------------ |
| `amonite-signing-key.asc` | Official Amonite Release Signing Key |

The release signing key is intended to remain stable over time and is
distributed separately from individual releases.

Always verify that the fingerprint matches the value published on the official
Amonite website before trusting the key.
